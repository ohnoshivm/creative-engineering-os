# Phase 1 & 2: Niche Selection + Canonical Agent Stack

## PHASE 1 — NICHE SELECTION (Mechanical, Not Creative)

### The Trap
"AI consulting" or "AI automation" = death in 90 days. Horizontal AI services are the most
commoditized category in the entire market. You compete on price, not value.

**The word "AI" in your offer signals: tool. Tools are evaluated on price.**
**The word "outcome" in your offer signals: value. Value is evaluated differently.**

### The Fix
Remove the word "AI" from your pitch. Replace it with the **specific recurring expensive
workflow** the buyer already pays someone to do badly.

**Pattern that holds at $50K MRR**: Recurring + high-intent + **narrow ICP**.
Narrow is the entire game.

### 3 Service Shapes Clearing $50K in 2026:

**1. Productized Service**
- Flat monthly retainer, fixed scope
- Public pricing on site — buyer chooses themselves
- No custom proposals, no sales calls for small tickets

**2. AI-Augmented Retainer**
- Custom scope per client
- Agents do the throughput, you own strategy + relationship
- Higher ticket, more touchpoints

**3. Async Deliverable**
- Outcome-based, no meetings, no calls
- Finished thing dropped into buyer's Slack on a recurring schedule
- The deliverable IS the product

### The Validation Rule (Unbreakable)
> The niche is real when 3 prospects pay a deposit.
> NOT when 30 say "interesting." NOT when 50 like your post on X.
> Cash on the table or the niche does not exist.

### Roman Agent Validation Workflow
Queue in #ops Slack channel. Roman:
1. Pulls TAM estimates for the niche
2. Scrapes last 30 days of job postings for the pain you solve
3. Surfaces trigger events putting the ICP into market right now
4. Builds 100-account list with named contacts + budget signals
5. Ranks top 3 pains by AI-leverage
6. Posts verdict as a one-page memo before you wake up

Run this against the 3 niches you're torn between. The verdict picks itself by the time
you read the second one.

**Median time to $10K MRR on this pattern: 6 months.**
If you haven't signed a deposit by month 4, the niche is wrong. Start again.
Do NOT push harder on a wrong niche for 9 more months hoping it cracks open.

## PHASE 2 — THE CANONICAL AGENT STACK

Pick once. Stop adding.

### The Stack

| Agent | Role | Notes |
|-------|------|-------|
| **Claude Code / Codex** | Engineer in the terminal — build environment | ~$200/month, most agencies switched in 2026 |
| **OpenClaw or Hermes** | Memory layer — persistent client context across sessions | Pick one, not both |
| **Roman (getroman.ai)** | The contractor in your Slack channel | Slack is not an integration for Roman — it's the entire surface |

**Total cost**: ~$200–300/month for the full stack.
**The wiring, not the tools, is the moat.**

### Where Each Agent Lives
- Claude Code / Codex → terminal, build environment, engineering tasks
- Memory layer → background, always-on, maintaining per-client context
- Roman → Slack channels, overnight runs, async deliverable production

### What NOT to Do
- Don't add agents because they're new and interesting
- Don't run 5 memory layers
- Don't wire Roman into a tool it doesn't need to touch

**Wire them into the right slot. The slot is decided by where the work happens.**
