Light, folded into form.

A realtime ribbon that bends with your pointer and folds as you scroll. Everything you read here is plain HTML underneath it.

See how it works

HTML first, then light

The page paints with real text and a drawn poster before any 3D code loads. The renderer arrives afterwards, in its own chunk, and only when the browser can run it.

One loop owns every frame. Pointer and scroll are read from small stores, so the scene never fights the reader for control of the page.

When motion is reduced, the scene renders a single still frame. Without WebGL, the poster stays and nothing is lost.

What this template proves

  1. Progressive enhancement. Poster first, renderer on idle, no loader.
  2. Single render-loop owner. gsap.ticker drives motion and the GL frame.
  3. Lit materials without downloads. An environment built in code, filtered with PMREM.
  4. Cleanup. Rendering pauses offscreen; each module's destroy() releases its resources on teardown.
